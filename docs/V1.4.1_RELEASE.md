# V1.4.1 完成记录

日期：2026-08-14

V1.4.1 按产品决策完全移除第一方 Backend Access Token 功能，恢复只需配置
Backend 地址即可连接云端服务的使用方式。

## 已完成

- Backend 删除 `ACCESS_TOKEN` 配置、`X-Access-Token` 校验中间件及相关 401 响应。
- Android/Web 客户端删除口令输入框、本地口令模型、请求头注入与未授权提示。
- 旧版本 IndexedDB 中的 `accessToken` 字段会在首次读取 Backend 配置时自动清除，
  不影响用户保存的地址或其他本地训练数据。
- 保留 `VOLC_ACCESS_TOKEN`：它是火山引擎旧版服务端鉴权凭证，只存在于 Backend，
  与已经删除的客户端访问口令不是同一功能。
- Web、Android、Backend 版本统一为 `1.4.1`，Android `versionCode` 为 7。

## 安全边界

Backend 现在不提供客户端身份认证，只适合受信任的家庭局域网。若部署到公网，
必须在反向代理、VPN 或 API 网关层增加认证、访问控制与限流。
