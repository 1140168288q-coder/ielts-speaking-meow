# 雅思口语喵｜执行 AI 启动提示词

使用方式：选择一个提示词复制给执行 AI。PDF 制作需同时提供 00_SHARED_BRIEF.md 与 01_PDF_PLAN.md；PPT 制作需提供 00_SHARED_BRIEF.md 与 02_PPT_PLAN.md。同一 AI 制作两版时先执行 PDF，再使用 PPT 提示词复用已核实素材，但分别排版。

以下提示词要求真正制作文件；当前任务只交付规划和提示词。
