# 从雅思口语喵提炼的 AI 应用技能包

这套技能面向**跨技术栈的 AI 应用**，覆盖从确定核心价值、实现、调试到部署、交付和演示的工作。共 12 个独立技能，每个包含可执行步骤、检查清单、适用与不适用场景、项目案例及 2 个迁移试用提示。

本包按用户要求保存在项目内，**未安装到全局**。技能不是业务代码模板，不要求使用 Android、React、FastAPI、DeepSeek 或 Cloudflare。

- 看制作过程与最终实现：[项目回顾](PROJECT_REVIEW.md)。

## 技能目录与适用情况

| 技能 | 适用情况 | 不宜用于 |
|---|---|---|
| [核心闭环与范围控制](skills/core-loop-scope/SKILL.md) | 产品功能越做越多、需要确定最小价值闭环，或退役已有能力并保留历史数据 | 普通文案修改、没有行为变化的局部修复 |
| [AI 契约与可靠性](skills/ai-contract-reliability/SKILL.md) | AI 返回成功但前端回退、字段漂移、状态误报、超时与重试不一致 | 只比较生成文风、普通非 AI 网络故障 |
| [异步流程与输入保护](skills/async-workflow-integrity/SKILL.md) | 旧结果覆盖新答案、并发保存丢字段、后续步骤被吞、草稿被重置 | 静态排版、单纯后端计费问题 |
| [AI 计量与幂等](skills/ai-usage-idempotency/SKILL.md) | 失败扣额、重复执行、多实例并发、同键异内容、缓存丢失 | 真实支付接入与财务合规 |
| [有来源的 RAG 与 Memory](skills/grounded-rag-memory/SKILL.md) | 个性化、知识导入、来源追踪、模型虚构用户经历、记忆开关无效 | 纯文案生成、只做检索性能调优 |
| [本地优先、同步与恢复](skills/local-first-sync-recovery/SKILL.md) | 离线存储、账号隔离、删除复活、同步重试、备份和历史迁移 | 无离线状态的简单 CRUD、直接设计多人 CRDT |
| [来源保真的导入管线](skills/source-import-pipeline/SKILL.md) | PDF/文档/结构数据周期更新、关系完整性、生成数据可再生 | 自由创作、一次性临时阅读 |
| [可中断的服务降级](skills/interruptible-provider-fallback/SKILL.md) | 云端到本地降级、语音互斥、取消与迟到结果、缓存配置失效 | 不可逆操作重试、没有等价备用能力的强保证任务 |
| [公网服务分层恢复](skills/public-stack-recovery/SKILL.md) | 本机正常公网失败、Tunnel故障、容器停止、监控失效 | 云厂商选型、未经授权改全局网络 |
| [有证据的版本交付](skills/evidence-based-release/SKILL.md) | 安装包、版本一致性、部署与业务验收，需要明确交付完成到哪一层 | 未请求的发布、小改也强制全面上线 |
| [可信演示与项目材料](skills/evidence-based-demo/SKILL.md) | 说明书、路演、视频，需区分真实运行与演示数据 | 概念广告、编造用户或效果指标 |
| [可恢复的协作与交接](skills/agent-delivery-handoff/SKILL.md) | 多阶段 AI 开发、已有用户改动、交给另一执行者、工具卡住 | 每次小改都写长计划或重复审批 |

## 如何使用

1. 从当前问题选择 1 个主技能；跨领域问题按边界组合，不需要一次加载全部。
2. 向执行 AI 提供该技能的完整目录，或让支持 `SKILL.md` 的环境加载它。直接对话时也可明确说“按这个文件执行”，并提供项目目标、目录和本轮约束。
3. 主文件是工作流程；需要理解取舍时才读 `references/case-study.md`。案例已经自含解释，原项目源码路径只用于溯源。
4. `evals/evals.json` 提供两个跨项目提示，可用于本地试用。它们不是已全部执行的自动化测试。
5. 每个技能可单独复制。保留该目录的 `references/` 和 `evals/`；无需复制其他技能、整个原项目或任何私人资料。

例如：

> 按 `ai-contract-reliability/SKILL.md` 排查我的客服助手。当前问题是 HTTP 200 后页面仍回退；先检查现有契约和日志，只修改这一条链路，不上线。

## 常用组合与分工

- 新产品或简化旧产品：核心闭环 → 协作交接 → 有证据的交付。
- AI 功能偶发失败：契约可靠性定位失败层；异步流程处理状态与写回；计量幂等处理重复成本。
- 用户知识产品：导入管线处理来源解析；RAG/Memory处理语义与事实；本地同步处理持久化和恢复。
- 云端语音：服务降级处理用户操作；公网恢复处理部署链路；版本交付检查最终运行证据。
- 答辩与展示：可信演示只使用版本交付中实际已有的证据，缺失部分明确标记。

## 迁移前替换什么

替换业务实体、允许输出、隐私政策、平台能力、部署方式和验收环境。超时秒数、缓存大小、Part分类、参考答案数量、固定题量、测试数量、域名和本机路径都不是通用默认值。

技能遵守目标项目既有约束和本轮授权：触发技能不代表自动获准删除数据、停生产、调用付费 API、安装到全局或发布。已明确授权的常规工作则不反复要求确认。
