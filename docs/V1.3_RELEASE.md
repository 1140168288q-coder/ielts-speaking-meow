# V1.3 完成记录

日期：2026-08-14

V1.3 在不做发音分和 IELTS 总分的前提下，增强可解释语音证据、两次回答反馈与
本地数据自主权。

## 已完成

- 新增本地 Web Audio 信号分析：解码原始录音后估算有效说话时长、静音占比、
  内部停顿数量、0.8 秒以上长停顿和平均停顿时长。
- 信号阈值根据录音噪声底和峰值自适应；短于 120ms 的自然微间隙会被合并。
  解码失败或信号不足时返回 `null`，绝不阻止原始录音保存。
- UI 在有可靠音频证据时显示静音占比和长停顿；本地反馈可把长停顿作为第二次
  回答动作，但始终标记为近似值，不输出发音分或 Band Score。
- 两次回答比较增加长停顿和静音信号；Text AI 的 `compareAttempts` 正式接入
  第二次回答界面。
- AI 对比使用两段 transcript 的 ID、文本和更新时间快照；任一转写变化后旧结果
  自动失效，过期网络响应不会覆盖新内容。
- 新增本地存储概览、按练习删除及关联录音原子删除、AI TTS 缓存清理。
- TTS 缓存限制为最多 40 项和约 25MB，超限时按创建时间清理最旧缓存；练习录音
  永不参与自动清理。
- 新增可移植 JSON 备份与恢复：包含练习、转写、个人表达和原始录音；恢复时先写
  录音，再写元数据，缺少被引用录音的损坏备份会在写入前被拒绝。
- BackendClient 对健康检查网络/超时/服务端错误进行一次短退避重试；所有请求
  附带 `X-Request-ID`，后端校验或生成安全关联 ID 并在响应头返回。
- Web、Android、Backend 版本统一为 `1.3.0`，Android `versionCode` 为 5。

## 重要技术决策

- 选择简单 RMS/VAD 风格的时间信号而非“精确发音评分”，避免把 transcript 或
  ASR 置信度伪装成声学事实。
- 备份采用版本化 JSON + base64 音频，优先保证无需云账号和第三方依赖；大数据量
  时文件会比原录音更大，因此设置 300MB 导入上限。
- 自动容量治理只清理可再生成的 TTS 缓存，绝不自动删除用户原始录音。

## 已知限制

- 不同手机麦克风、自动增益和环境噪声会影响停顿阈值；所有声学结果仅作为近似
  训练提示。
- 浏览器下载在少数定制 Android WebView 上可能交给系统下载管理器处理；备份服务
  本身已通过真实浏览器下载和往返测试。
- 没有真实付费云端密钥，因此 AI 对比使用 Provider/Mock 全链路验证，未消耗真实
  API 配额。
