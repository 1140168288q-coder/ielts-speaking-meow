## 项目经验

项目用“两次回答→确认表达/个人信息→保存复用”贯穿材料。技术表述选择“应用编排、用户参与确认的训练工作流”，没有将固定规则计划包装为自主智能体。

2026-09-14材料共同说明采用源码/历史自动化/本次实测/后续计划分级；为PDF独立阅读与PPT现场讲述分别编排。后续录屏脚本与虚构历史数据使用隔离账号和原生备份恢复。
