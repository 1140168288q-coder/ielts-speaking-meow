# V1.2 计划:云端 Backend 托管第三方 API

状态:**V1.2 已发布(2026-08-14)**。三大能力全部真实跑通;STT 2.0/
health 驱动降级/运行时地址配置/正式 Release 签名均已完成;真机实测功能正常;
部署服务器为可选。验收详见 `docs/android-acceptance-v1.2.md`。

## 目标架构

```
Android App ──HTTP──▶ 自建 Backend(FastAPI) ──▶ DeepSeek(Text AI)
                     │                        ──▶ 火山引擎 流式语音识别(STT,WebSocket 直传)
                     │                        ──▶ 火山引擎 语音合成 2.0(TTS)
                     └ 密钥只在环境变量,不进入 APK / 仓库 / 客户端配置
```

## 已完成(全部真实凭证验证)

### Backend(`backend/`,Python 3.12 + FastAPI)

- 接口:`GET /health`、`POST /v1/stt`(multipart WAV→流式直传火山)、
  `POST /v1/feedback`(DeepSeek,一次反馈/两次对比)、`POST /v1/tts`(SSE 合成→mp3)、
  `POST /v1/organize`(导入材料整理)
- 服务拆分:`DeepSeekService` / `VolcengineStreamingSTTService` / `VolcengineTTSService`
- **STT 采用流式语音识别**(2026-08-13 决定,替代原「录音文件识别 2.0」):
  - 原因:录音文件识别要求音频放在公网 URL 上(必须买服务器);流式把音频分帧
    WebSocket 直传,后端跑在家庭电脑上即可完整工作
  - 协议按官方文档(6561/1354869)与官方 SDK(doubao-speech-go)逐字节核实:
    端点 `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel`,二进制帧协议、
    负序号最终帧、`X-Api-Key` + `X-Api-Resource-Id` 鉴权
  - `enable_ddc`(语义顺滑)保持关闭,忠实保留 filler/重复/自我修正
  - 真实验证:Windows TTS 合成英文 → `/v1/stt` → 火山准确转写,耗时约 1.3 秒
  - 资源 ID:当前使用 2.0 `volc.seedasr.sauc.duration`(账号已开通 2.0);
    未开通 2.0 的账号改用 1.0 `volc.bigasr.sauc.duration`
- DeepSeek 真实反馈验证通过(结构、质量符合产品要求);TTS 真实合成验证通过。
  音色实测:本账号仅 uranus 系列可用(`zh_female_vv_uranus_bigtts` /
  `zh_female_xiaohe_uranus_bigtts`),mars/moon/英语音色均返回 55000000,
  默认音色保持 `zh_female_vv_uranus_bigtts`;控制台开通英语音色后可切
  `en_female_anna_mars_bigtts`
- 安全基线:上传 25MB 限制、WAV 300 秒时长限制、应用不持久化上传音频
  （multipart 可能使用框架管理的短期 spooled 临时文件）、会话超时、日志脱敏、
  内存限流预留(默认关闭)
- `.env.example` 全参数占位;`.env` 已被 `.gitignore` 排除
- pytest 34 项(DeepSeek/TTS 用 MockTransport,流式 STT 用本地假 WebSocket 服务器)

### Android 客户端

- 新增 `BackendTextProvider` / `BackendSttProvider` / `BackendTtsProvider` +
  `BackendClient`,实现原有 `LLMProvider` / `RecordedAudioSTTProvider` / `TTSProvider`
  端口;录音上传前经 Web Audio 转 16kHz WAV(客户端契约未变,换 STT 产品对 App 无感)
- Backend 地址构建期注入(`VITE_BACKEND_URL`)作为默认值;运行时可在
  App「设置 → 云端服务」配置地址(IndexedDB v3 `backendConfig` store)
- 删除普通用户的第三方 API Key 配置(ApiSettingsPanel、ApiConfigurationService、
  OpenAI-compatible providers、客户端密钥安全存储);练习数据不受影响
- 设置页改为:云端连接状态(启动自动检查 `/health` 并缓存,三供应商真实状态
  驱动各 Backend provider 的降级决策)+ Backend 地址/口令配置 + 本机能力测试
- 网络策略:允许明文流量以支持用户自配的局域网 http 地址;生产部署请用 HTTPS
- App.tsx 练习流拆分为 `src/features/practice/`(PracticeFlow / LibraryViews)

### 家庭本地使用(第一形态)

- `backend/start.bat`:双击启动后端(监听 0.0.0.0,首次防火墙弹窗点「允许」)
- 手机与电脑连同一 WiFi,安装 APK 后在「设置 → 云端服务」填入电脑局域网
  地址即可使用全部云端能力(IP 变化无需重新打包)
