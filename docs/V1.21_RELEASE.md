# V1.21（SemVer 1.2.1）完成记录

日期：2026-08-14

V1.21 是从 V1.2 到 V1.3 之前的可靠性版本，不扩大 IELTS 产品范围。

## 已完成

- 录音期间切换应用、锁屏或触发页面隐藏时，自动停止并先保存原始录音；有本机
  实时转写时一并保留，没有转写时保存为可重试、可手工编辑的中断记录。
- Release 构建缺少 `android/keystore.properties` 时强制失败，不再静默回退
  debug 签名；正式产物复制前使用 `apksigner` 校验证书。
- Android、Web、Backend 版本统一为 `1.2.1`，Android `versionCode` 升至 4；
  构建产物名称从 `package.json` 自动读取版本。
- 新增 `npm run test:backend` 与 `npm run verify`，统一覆盖类型检查、ESLint、
  前端测试、后端测试和生产构建。
- 修复 ESLint 扫描 Python/Gradle/测试缓存导致的全仓库 lint 失败。
- 新增后端直接依赖锁定文件 `backend/requirements.lock.txt`。
- `/health` 响应在客户端通过 Zod 做运行时校验，非法结构按可重试的
  `invalid-response` 处理。
- 公网 Backend 地址强制 HTTPS；HTTP 只允许 localhost、`.local`、回环与私有
  局域网地址，设置页会提示局域网明文传输风险。
- 修正文档中“上传音频绝不落盘”的绝对描述：FastAPI multipart 可能使用
  框架管理的短期 spooled 临时文件，应用不创建持久录音文件。
- 增加内联 favicon，消除生产预览中的无意义 404 控制台错误。

## 验证

- `npm run verify`：通过；前端 30 个测试文件、184 项测试通过，Backend 41 项
  测试通过，生产构建通过。
- Playwright 生产预览：题库、进入练习、录音入口及麦克风拒绝降级文案实际运行
  正常；页面没有应用级控制台错误。
- `npm run android:build`：通过；Android Debug APK、Java 单测与 Android Lint
  均成功，产物为 `artifacts/ielts-speaking-meow-v1.2.1-debug.apk`。
- Debug APK SHA-256：
  `92ea284f6dbc3e9175023f89c4ee78fca89938338d62543df7a8729f22dbf2d7`。

## 已知限制

- Web MediaRecorder 无法在操作系统强杀进程后继续执行异步落库；本版本覆盖应用
  切后台、锁屏和正常生命周期事件。极端强杀保护需要未来原生录音服务。
- 没有真实云端密钥，因此没有在本版本验证付费供应商在线调用；Mock 与本地失败
  降级路径已覆盖。
