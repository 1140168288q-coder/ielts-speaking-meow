# 雅思口语喵 V1.1 开发计划

## 目标与边界

V1.1 在不改变“两次真实开口”核心闭环的前提下，补齐两类能力：

1. 从用户自己的材料中导入口语题；
2. 让 Text AI、Voice AI、STT 可以分别接入 OpenAI-compatible API。

不新增模拟考试、实时 AI 考官、官方分数、精确发音评分、账号云同步、社交、
桌面端或 iOS。

## 阶段

### 1. 本地材料导入

- 支持 TXT、MD、DOCX、PDF、JPG、PNG；
- TXT / MD / DOCX / 文本型 PDF 在本机提取文字；
- 扫描 PDF、JPG、PNG 使用 Android bundled ML Kit 在本机 OCR；
- 所有候选题先预览，可修正 Part、主题、题目与 Part 2 提示点；
- 重复题默认跳过，用户可明确选择仍然导入；
- 源文件、提取文字、导入题目使用同一个 IndexedDB 事务提交；
- V1.0 的练习、表达和录音存储只做增量迁移，不破坏旧数据。

### 2. 三套独立 API

- Text AI：Provider、HTTPS Endpoint、Model、API Key；
- STT：独立 Provider、HTTPS Endpoint、Model、API Key；
- Voice AI：Provider、HTTPS Endpoint、Model、Voice、API Key；
- Android API Key 由 Keystore AES-256-GCM 加密，配置与密钥分离保存；
- 远程 STT 只读取已经本地保存的原录音；成功或失败都不删除录音；
- Voice AI 失败时自动回退 Android System TTS；
- Text AI 返回值必须通过运行时结构校验，失败时继续显示本地反馈。

### 3. 验收门禁

- 类型检查、ESLint、全量 Vitest、production build；
- API 36 Android assemble、unit test、lint、connected instrumentation；
- 浏览器实走“导入 → 确认 → 保存 → 重启恢复”；
- Android 实走本地 OCR、Keystore 密钥往返、System TTS、录音与持久化；
- 生成可侧载的 V1.1 Debug APK，并记录 SHA-256 与已知边界。
