## 3. 核心叙事与四项特色

推荐标题：**雅思口语喵**。

副标题：**围绕两次回答与个人记忆的 AI 口语训练助手**。

定位句：**让每次练习，都留下下一次能用上的表达。**

技术说明统一使用：**应用编排、用户参与确认的垂直 AI 训练工作流**。

### 特色 A：把反馈接到第二次回答

第一次回答后突出 2–3 项问题，再通过训练小计划引导第二次回答，完成后可回看两次文本与确认成果。创新表述聚焦“把诊断、再练与积累组织成一次训练”；不宣称双答训练是全球首创。

### 特色 B：两个参考版本承担不同职责

简单优化版基于用户原答案纠错，保留原意；自然提升版才可结合适用教学知识、个人知识库与 Memory 补充内容。自然提升支持三档难度与英美文本风格，并保存当次配置。可替换 AI 示例与个人来源需区分。创新表述聚焦“事实边界与可模仿难度的结合”，不承诺所有输出永远正确。

### 特色 C：可追溯知识与经确认的 Memory

教学 RAG、个人知识库和用户 Memory 职责不同：教学 RAG 提供训练原则；个人知识库存储整理并确认的导入内容；Memory 根据真实持久化练习、表达、素材与已确认事实组织用户上下文。检索采用本地规则，不是向量数据库，不是训练一个专属模型。

知识库中的第一人称句子不能自动变成用户经历。二答分析只依据当前二答提取候选，不引用原有 RAG/Memory 来“证明”新事实；候选经过来源句检查并由用户确认。称为“受控积累”，不称为“自动学习用户一切”。

### 特色 D：有依据的行动与可回看的交付

训练计划把目标、1–2 项行动、教学或个人素材依据和完成结果放在一起。成果是两次用户回答、反馈、确认表达与个人信息。检索、TTS、存储和流程控制由应用提供，部分动作由用户触发；当前没有模型自主选择工具与循环规划。
