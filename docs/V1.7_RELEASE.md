# V1.7 完成记录

版本：`1.7.0`（Android `versionCode 10`）

## 本次改动

### 1. 彻底移除 STT

- 客户端：删除 `WebSpeechSTT`、`BackendSttProvider`、`audioToWav`、STT 端口、
  设置页 STT 状态行，以及录音页里的实时转写、云端转写重试和相关 UI。
- Backend：删除 `/v1/stt` 路由、火山流式语音识别服务、STT 配置项、
  `.env.example` 中的 STT 环境变量、`websockets` / `python-multipart` 依赖与
  相关测试。
- Android：移除 `RECORD_AUDIO` 权限和 `android.hardware.microphone` 强制声明。
- 用户答案改为系统键盘语音输入或手动输入文本；应用内不再录音、不再转写。

### 2. 可选计时器

- 每次回答提供手动开始 / 暂停 / 继续 / 重置；
- 不自动计时、不强制结束、不自动提交；
- 若使用计时器，作答时间随答案提交给 DeepSeek，仅作参考，不参与语速评价。

### 3. DeepSeek 只分析文本

- 请求只含：Part、题目、用户答案、可选作答时间；
- 分析：语法、词汇、连贯性、表达自然度、是否切题、内容展开；
- 明确禁止评价 Pronunciation、语速、停顿、语调；
- 整个应用不再展示或生成任何 IELTS Band 分数、分数段或水平评分。

### 4. 新 Prompt 与结构化输出

- 角色：友好的 IELTS Speaking Tutor；
- 优先最重要问题，不过度纠错；优化答案保持用户原本水平和表达习惯；
- 每道题返回恰好 3 个自然口语参考回答：简单自然版 / 自然提升版 / 另一种表达版；
- 结构：`summary` / `strengths` / `problems` / `grammarSuggestions` /
  `vocabularySuggestions` / `improvedAnswer` / `referenceAnswers(3)`；
- 客户端和 Backend 都做运行时 schema 校验。

### 5. TTS 优化

- 题目、优化答案和 3 个参考回答均可试听；
- 同一按钮第一次点击播放，第二次点击立即停止；
- 播放 A 时点击 B：AudioCoordinator 先停止 A 再播放 B；
- 全局同时只有一个 TTS 播放。

### 6. UI 精简

- 删除录音、转写重试、跟读和发音复盘相关按钮与文字；
- 仅保留一行弱提示：可用手机系统键盘语音输入；
- 首页默认三行文字不再默认展示“口语目标分：6.0”。

## 兼容与迁移
