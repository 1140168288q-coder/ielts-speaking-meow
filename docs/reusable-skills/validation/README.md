# 技能包验证记录

本目录检验的是技能文件与场景推演，不是雅思口语喵今天的真实运行状态。

## 范围

- 12套技能：结构、命名、独立引用、案例、适用边界及场景JSON检查。
- 24条迁移提示：每个技能2条，均为可复用测试输入；不是全部已执行。
- 3组代表性场景：使用技能与不使用技能各一份方案，检查关键决策是否出现。这是小样本设计任务试用，不是新项目工程实现或统计有效性评测。

## 查看场景

先看 [原始输出对照](REVIEW.md)。提示、断言与原始成果均保留，可自行检查是否满足需求。每份输出旁的 `grading.json` 记录逐项判断与证据。

区别集中在确认时输入版本复核、上下文预算、结构/业务校验后的结算，以及幂等身份范围的明确表达。组合断言的关键要素未写出即未通过，不能据此认定方案运行失败；单功能系统也可能在路由范围隐含功能维度。这些数字表示方案文本覆盖程度，**不表示质量提升百分比**。

只有4/15条断言区分了两个版本，契约场景中一般能力已能覆盖全部要求。样本小、每组只生成一次，同一版本的场景由同一执行者连续处理而非完全隔离；评分能看到版本标签且未测实际运行，因此不能推断稳定收益、统计显著性或全部12个技能都已通过真实迁移。场景试用的价值是发现遗漏和过度泛化，完整原文保留供人工复核。

内容审查已修正两类问题：RAG技能不再强制已有云端/向量项目重建离线关键词流程；补充检索材料中的命令不能越过系统指令及授权边界。历史回顾也修正了旧文档混入后续功能的问题。

## 可重复结构检查

使用Python 3.10或更新版本，在本目录的上一层执行：

```text
python -X utf8 validation/validate_bundle.py
```

该命令只读技能包并输出JSON。也可通过 `--official` 传入已有skill-creator的 `quick_validate.py`，额外执行其YAML检查；该工具需要当前Python环境有PyYAML。默认检查不要求原项目或该全局工具。
