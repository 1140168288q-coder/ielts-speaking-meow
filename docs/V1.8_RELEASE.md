# V1.8 完成记录

版本：`1.8.0`（Android `versionCode 11`）

## 本次改动

### 1. 最新季度题库自动解析并替换旧内置题库

- 新增 `scripts/import-question-bank.mjs`：用项目内已有的 `pdfjs-dist`
  解析《更新版-2026年5-8月雅思口语新题库0526(1).pdf》；
- 输出 `src/data/questionBank.generated.json`，题量：
  - Part 1：256 题（43 个 topic）
  - Part 2：60 题（cue card）
  - Part 3：337 题
- 每个 Part 2 都保留 cue points 和 `relatedPart3Ids`；每个内置 Part 3
  都保留 `part2QuestionId` 回链；new/old、category 全部保留；
- V1.4 旧内置题从浏览/随机抽题中删除，只保留在 `legacyQuestionsById`
  用于显示历史练习记录；
- 题库浏览新增季度标题、搜索、只看新题、分类分组；Part 2 可展开
  “对应 Part 3”并直接开始任意一道跟进题；
- 换季度命令：`npm run question-bank:update -- "<新题库.pdf>"`，机制见
  `docs/QUESTION_BANK_UPDATE.md`。

### 2. 简易本地账号与数据隔离

- IndexedDB v5 新增 `accounts` store；首次启动自动创建“本机用户”；
- 账号 = 昵称 + 稳定 `userId`（未来云同步身份键）+ 可选 4-6 位本地 PIN
  （只存 SHA-256 摘要，用于防误切换，不是加密）；
- `TrainingSession` / `SavedExpression` / `ImportedQuestionRecord` 增加
  `ownerId`；`PracticeService` 与导入服务读写时按当前账号过滤；
- V1.8 之前没有 ownerId 的数据自动归“本机用户”，不会丢失；
- “我的”页面可创建账号、输入 PIN 切换；切换后练习、表达、导入题
  互不可见；
- 未做社交、会员、云端注册。

### 3. IELTS 教学 RAG

- 本地词汇检索知识库（Part 匹配 + 主题词重叠），十几篇自写教学原则，
  不引入向量库 / embedding API；
- 练习页显示“本题备考要点”，离线可用；
- `buildTutorContext` 生成紧凑教学上下文，随 `/v1/feedback` 发送到
  自建 Backend（第三方密钥仍在 Backend）。

### 4. 用户长期 Memory 与素材跨题复用

- 长期记忆由真实 sessions/expressions 聚合：本题练过次数、近期反复
  问题、近期被肯定的地方；
- 跨题复用排序：同题 > 同 topic > 关键词相近 > 同 Part；
- 练习页展示“你的长期素材”，可试听、可一键插入当前答案框；
- 插入后 `reuseCount` +1，成为后续排序依据；`learnerContext` 随反馈
  请求发送，DeepSeek 会自然参考但不会整段背诵。

### 5. AI 反馈 UI 精简

- 默认只展开：整体小结 + “优先改这 2-3 点”；
- 语法微修、词汇替换、优化答案改为折叠 `<details>`；
- 3 个参考回答改为 tab 切换，一次只读一篇；
- Backend Prompt 同步收紧：summary 最多两句、problems 每条一句动作优先。

### 6. 不变的产品边界

- 不评分、不输出 Band Score / 分数段 / 水平评价；
- 不评价发音、语速、停顿、语调；
- 不恢复 STT / 应用内录音 / 转写；
- 第三方 API Key 只存在于 Backend 环境变量。

## 已知限制

- 本地账号 PIN 是防误切换保护，不是加密或找回机制；
- RAG/Memory 是第一版轻量实现：跨语言语义匹配有限，未来若题库/知识库
  变大再考虑向量检索；
- 云同步只预留 userId，尚无实际同步服务；
- 导入材料整理的 AI 组织接口尚未使用教学 RAG 上下文，保持 V1.7 行为。
