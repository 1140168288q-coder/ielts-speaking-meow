# V1.4 完成记录

日期：2026-08-14

V1.4 将已经完成的单次练习连接成可持续的本地学习过程：个人表达可以反复使用，
第二次回答的长期变化可以被看见，下一题也能参考真实练习历史。

## 已完成

- 个人表达支持英文/主题搜索、编辑、删除、示范播放、跟读打卡和返回原题再练。
- 新增轻复习队列：从未跟读或超过 7 天未跟读的表达优先出现，每次最多提示 3 句；
  这是透明的本地规则，不扩展为复杂间隔重复系统。
- 表达新增可选的更新时间、跟读次数和最近跟读时间字段；旧版数据无需迁移即可
  继续读取，新增和更新仍通过运行时 Schema 校验。
- 新增“进步”页：汇总真实开口次数、第二次回答完成率、可见改善比例、两次回答间
  填充词/长停顿平均变化、常练主题和反复出现的高置信度重点。
- 进步页不会估算 IELTS 分数或发音分；缺少可靠录音/对比证据时显示暂无数据，
  不会猜测。
- 题库增加可选难度和来源元数据；内置题按 Part 标记基础/进阶/拓展，导入题保留
  “用户导入材料”来源，历史旧题仍兼容。
- 首页与进步页新增历史驱动推荐：优先补足练得较少的题目、主题和 Part，并降低
  刚练完题目的优先级；所有计算均在本机完成。
- Web、Android、Backend 版本统一为 `1.4.0`，Android `versionCode` 为 6。

## 重要技术决策

- 进步只使用录音时长、转写中填充词/重复词和可用的本地停顿信号，避免把主观
  学习趋势包装成考试评分。
- 推荐采用可解释的覆盖度排序，不上传学习历史，也不引入难以验证的黑箱模型。
- 轻复习只解决“保存后还能再说一次”，不在本版本引入打卡日历、连续天数、社交
  排行或完整 SRS。

## 已知限制

- 历史数据较少时，推荐主要依据题目/主题是否练过；积累更多两次回答后进步摘要
  才更有代表性。
- 导入题的难度目前按 IELTS Part 给出默认值，未声称是官方难度评级。
- 没有真实付费云端密钥，因此云端 AI 对比继续通过 Provider/Mock 验证。
