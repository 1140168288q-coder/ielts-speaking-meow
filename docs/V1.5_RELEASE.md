# V1.5 完成记录

日期：2026-08-15

V1.5 按 Codex 只读审查结论修复云端状态判断、语音选择、TTS 缓存、导入
整理与正式包地址五类问题，并把版本统一升到 `1.5.0`。

## 已修复

### 1. 正式包固定 Backend 地址

- 正式构建（`VITE_LOCK_BACKEND_URL=true`）把 Backend 地址写死进安装包，
  设置页只展示连接状态、Backend 版本、供应商详情与本机能力，**不再出现
  地址输入框**；
- 构建期（`vite.config.ts`）与打包脚本（`scripts/android-build.ps1`）双重
  校验：正式构建缺少地址直接失败；默认强制 HTTPS；家庭 Backend 的私有
  局域网 HTTP 例外必须显式 `-AllowLanHttp`，公网明文 HTTP 与模拟器缺省
  地址永远不允许进入正式包；
- 升级后首次启动自动清除旧版本保存在 IndexedDB 的运行时地址
  （`BackendConfigStore.load()` + `clearBackendConfig()`），内置地址不可能
  被旧数据覆盖；
- 调试构建保持原有行为：默认 `10.0.2.2:8000`、设置页可编辑。

### 2. /health 展示真实验证状态

- `/health` 返回每个供应商的 `configured`、`model`、`resourceId`、
  `speaker {id, name}` 与 `verification`（unverified / verified / failed +
  最近调用时间、延迟、安全错误摘要、STT 最近转写样例），不再只是布尔；
- 新增 `POST /health/verify`：DeepSeek 一次 32 token 的小规模补全（`deepseek-v4-flash`
  是推理模型，需预留思考 token）、TTS 合成一句 "Hello."，做真实小规模验证并写回
  verification；STT 需要真实音频，只返回最近一次转写结果；
- 三个服务（DeepSeek / 火山 STT / 火山 TTS）每次真实调用都记录最近结果
  （`backend/app/services/verification.py`）；密钥无效或未开通资源权限时
  设置页显示「验证失败」，绝不显示「已连接」。

### 3. 无后端立即系统播报 + 本机 TTS 检测

- `BackendTtsProvider` 在健康状态未知（Backend 不可达 / 尚未检查完成）时
  直接不可用，`FallbackTTSProvider` 立即切到 Android 系统 TTS，不再等 60 秒
  云端超时；
- 云端合成失败后进入 60 秒短期熔断，期间同样直接走系统 TTS；成功自动复位；
- 设置页「测试系统朗读」直连 `CapacitorSystemTTS`，不再走 AI 优先链路；
- `SystemTTSPlugin`（Java）新增 `status()`：返回默认引擎名、已装引擎列表、
  英语语音包可用性；设置页展示引擎与英语语音包状态，缺失时明确提示
  「安装英语语音包或切换引擎」，而不是“正在播报”但无声。

### 4. TTS 参数与缓存键

- `/v1/tts` 支持 `language` / `rate` / `pitch`，后端映射为火山
  `speed_ratio` / `pitch_ratio`（0.5–2.0 钳制）；客户端把 en-US、0.92 等
  请求参数如实转发；
- AI TTS 缓存键扩展为
  `text + provider + model + speaker + language + rate + pitch + voiceConfigVersion`，
  服务端换音色后相同文本不再命中旧音频；
- 升级后清理一次旧 AI TTS 缓存（`TTS_VOICE_CONFIG_VERSION=2` 落盘标记，
  首次启动比对后执行 `clearTtsCache()`）。

### 5. 移除“进步”页

- 删除「进步」底部导航与 `ProgressDashboard` 组件及样式；
- 练习记录、两段原始录音、个人语料、轻复习与首页本地推荐全部保留，
  `domain/progress` 中的推荐与复习规则继续工作。

### 6. DeepSeek 导入整理常驻可选

- 导入预览中「用 DeepSeek 智能整理」常驻显示（未配置时禁用并说明），
  不再只在本地完全找不到题目时出现；
- DeepSeek 失败或返回空结果时，本地候选题原样保留，可一键继续人工确认。

## 已知限制

- Release 包内置的是局域网 HTTP 地址，属于 Codex 方案的显式例外
  （家庭 Backend 尚未有公网 HTTPS 域名）；地址变化时需重新打包 Release，
  Debug 包仍可运行时修改；
- 云端 TTS 状态「未知」的判断依赖启动时的 `/health` 快照：Backend 在
  快照之后才失联时，首次播放会走云端并快速失败回退（连接拒绝场景 <1s）；
- STT 无音频探针，其「已验证」状态来自真实转写调用；
- 火山音色仍为 `zh_female_vv_uranus_bigtts`（vivi 2.0）：在控制台开通
  英语音色后改 `VOLC_TTS_SPEAKER`（如 `en_female_anna_mars_bigtts`）并用
  设置页「试听云端音色」真人验收即可，客户端无需改代码。

## 当日热修复（2026-08-15 晚）

- DeepSeek 验证探针原用 `max_tokens: 4`，而 `deepseek-v4-flash` 是推理
  模型，4 个 token 会被思考过程耗尽导致 `content` 为空、验证误报失败；
  已改为 32 token 并接受 `reasoning_content`，只要上游 200 且可解析出
  消息即判定 verified（实测 DeepSeek 802ms 返回 OK，`/v1/feedback` 端到端
  200）；
- 新增根目录一键启动脚本 `start-backend.bat`：双击即启动后端、自动检测
  端口占用、输出本机局域网地址与手机连接地址、打开 `/health` 状态页。
